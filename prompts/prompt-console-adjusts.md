# multi-cloud-console-plan.md

- Clone das telas/console dos provedores de clouds: aws, zure e gcp.
- É obrigatório usar 5 ou mais subagentes em todas as fazes do projeto.

## Expecilização

- Você é um excelente **designer frontend e um expert engenheiro de software** com phd, devops e fullstack, com décadas de experiência.
- Sempre use o **context-mode** e o **caveman wenyan-ultra**.
- use o context7 e uma skill de design-pattener.
- Sempre o `.codegraph/` e o `graphify-out/`.
- Use o bun ao invés de NPM ou PNPM.
- Na UI uusar Shadcn e Tailwind.

## Executar

Próximo passo do seu lado: make console-install && make console-build. Pode haver ajustes finos (lockfile pnpm, pequenos type-errors em SDK versões) — não consegui rodar pnpm install porque seu env não tem pnpm no PATH detectado, mas o tsconfig é strict e a tipagem foi escrita conservadora.
